CGTMSE Resubmit Desk

Works on Python 3.14 (C:\Python314\python.exe). Do not use py -3.

1. Unzip this folder
2. Double-click run.bat
   (or START_DESK.bat if you only have Python 3.14)
3. Open desk
4. Files tab: credential master + claims data
5. Optional: maker / checker fallback passwords, comma separated
6. Build queue → Run → Start live run

Output: output\RESUBCL-dd-mm-yyyy-HH-MM\

Do not double-click an old run.bat that says "No Python 3.10-3.13 found".
That file is obsolete. Replace it with this one.
